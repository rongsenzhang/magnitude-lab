# Cantabular and the work behind a flexible statistics service

Public evidence reviewed on 20 November 2026. This review asks what a statistics agency buys, what the software already does, and where an independent magnitude-data experiment could add evidence.

## What the business sells

Cantabular Ltd, formerly The Sensible Code Company Ltd, licenses software that lets a statistics producer publish data and explanatory metadata together. Readers choose a population, grouping and output. The software can compute a table from underlying records, apply the producer’s disclosure rules and return the result on demand. It can also serve tables the producer has prepared. The audience includes the public and researchers working in controlled environments. The company describes additional customers in finance, government and media across the US and Europe. The named census deployments provide the clearest public evidence. [Company profile](https://cantabular.com/about-us) · [Product manual](https://docs.cantabular.com/latest/)

| What the customer buys | How the organisation uses it |
|---|---|
| Public dissemination | A member of the public can choose variables, filter, pivot, preview and download a table. The producer can provide multilingual metadata, ready-made tables, map selection and CSV or Excel outputs. [Public dissemination](https://cantabular.com/use-cases/public-data-dissemination) |
| Researcher access | A data custodian can automate checks on requested tables in a trusted research environment. Configurable checks can block a query or suppress results, including cells affected by dominance. Analysts receive feedback while records stay with the custodian. [Researcher access](https://cantabular.com/use-cases/safe-researcher-access) |
| Implementation services | Staff help build ingestion pipelines, validate data dictionaries, customise interfaces, integrate with existing systems and create maps or dashboards. Customers can deploy within their own infrastructure, in a private cloud, or with the vendor. [Integration services](https://cantabular.com/services/data-pipelines-and-integration) · [Visualisation services](https://cantabular.com/services/data-visualisation) |
| Licence | The main price driver is the annual volume processed, with a minimum licence fee. The published model permits multiple servers and users without separate charges for each. The pricing page gives no cash quote. [Pricing](https://cantabular.com/pricing) |

## The problem a buyer recognises

NISRA’s own evaluation describes the cost of publishing fixed tables. Some combinations that users needed were unavailable, while some tables prepared and checked by staff went unused. A custom table builder lets users ask for the breakdown they need. For each publication decision, the system must return a useful result quickly and apply disclosure checks to each generated output. NISRA reports testing accessibility, data and metadata accuracy and disclosure parameters before release. Its team provided training, video guides and continuing support. [NISRA project evaluation, especially §§2–4](https://www.nisra.gov.uk/system/files/statistics/2025-04/census-2021-nisra-flexible-table-builder-project-evaluation-v1.pdf)

| Evidence | Implication for the demonstration |
|---|---|
| For the 2021 England and Wales census, ONS deployed the software inside its own environment, supplied its own interface and accessed tables and metadata through the API. Cantabular reports integration, training and iterative reviews with ONS staff. [ONS case study](https://cantabular.com/case-studies/office-for-national-statistics) | Give the release output an explicit format so another client can consume it and verify its interpretation. |
| NISRA started with representative synthetic data, automated metadata processing and checks using Python and GitHub Actions, and validated actual census data in its own environment. Users can build custom tables or choose and customise existing ones. [NISRA case study](https://cantabular.com/case-studies/northern-ireland-statistics-and-research-agency) · [Live NISRA service](https://build.nisra.gov.uk/en/) | Provide reproducible inputs and outputs, human-readable controls and an independent rerun from the repository. |

## Existing research and the opportunity for v1.0

**Magnitude protection already exists at Cantabular.** The company describes an initial implementation developed with a national statistics institute. Its published approach uses cell-key perturbation, top coding, perturbation of magnitudes and disclosure rules. It illustrates income aggregates with synthetic EU-SILC data and describes ongoing evaluation across datasets. A reproducible comparison of release policies, outlier effects and small-area utility therefore addresses a recognisable research question. Applicants can show where a policy performs poorly as well as where it works. [Magnitude methods](https://cantabular.com/blog/protecting-magnitude-tables-with-cantabular) · [EU-SILC preparation and linkage](https://cantabular.com/blog/linking-eu-silc-datasets-unlocking-insights-with-cantabular)

**The product includes an integration boundary.** The public manual covers codebooks, input formats, the disclosure rules language, query processing, metadata, GraphQL and JSON-stat. The extended API joins results to owner-defined metadata, including localised labels and definitions. The installation guide describes a licence file. An independent demonstrator can publish a documented output contract and an integration proposal. Vendor acceptance, a licensed installation and evidence from real workloads would be separate milestones. [Extended API](https://docs.cantabular.com/latest/extended-api-guide/index.html) · [Disclosure rules](https://docs.cantabular.com/latest/disclosure-rules-language/index.html) · [Installation](https://docs.cantabular.com/latest/installation-guide/structure.html)

**Geography changes the statistical question.** A regional result may look usable even when one component area contains few contributors or one dominant business. Check local coverage and distortion alongside regional estimates. Cantabular’s historical census articles show why users want to select and explore areas. Its separate US census demonstration computes intervals using 50 replicate privacy-protected microdata files, illustrating how uncertainty can vary across breakdowns. A measured error on synthetic data should carry its own definition and denominator. [Geographic selection example](https://cantabular.com/blog/maps-explore-1911-ireland-census) · [US census interval demonstration](https://cantabular.com/blog/explore-the-us-census-2020-with-cantabular)

**AI is a route for asking questions.** In its public work on responsible AI, the company assigns computation and privacy protection to deterministic statistical software. The interface retrieves statistics and metadata for a requested question. In an application prototype, a second interface should consume exactly the same released values, suppression statuses and units as the visual table. A structured example query can demonstrate that contract without a model service. [Responsible AI and MCP](https://cantabular.com/blog/responsible-ai-in-official-statistics-with-the-model-context-protocol-mcp-) · [AI and official statistics](https://cantabular.com/blog/integrating-ai-into-official-statistics)

## Site coverage

The [page inventory](company-pages.csv) records 123 normalised URLs, their observed HTTP status and their page title when available. Starting at the homepage, the review followed ordinary same-site links through navigation, footers, related articles and all three blog listing pages until there were no new links. It also followed links from the current technical manual across its seven guides. Fragment identifiers, duplicate pagination, static assets, search/index utilities and tracking parameters were excluded. The public sitemap probe yielded no usable sitemap, so unlinked pages may exist.

| Site or collection | Observed coverage |
|---|---|
| Main company domain | 73 linked URLs checked. 66 returned page content, including 39 journal articles, three journal listing pages, eight staff biographies, two case studies, both listed use cases, both service pages, commercial information, policy pages and the Python cell-key example. Seven linked routes returned HTTP 500 on repeat access. Their rows retain the failed status and an empty page title. |
| Current product documentation | 50 content pages retrieved from the public 10.7.5 manual. Sections cover installation, data loading, codebooks, release notes and testing, extended API, metadata service and disclosure rules. [Documentation](https://docs.cantabular.com/latest/) |
| Connected examples on other domains | The Northern Ireland live builder and mapping demo, historical Irish census and US census demo entry pages returned HTTP 200. The synthetic EU-SILC demo entry returned HTTP 403 to the reviewer. The description of this example comes from the company’s published technical account. This inventory covers documentation and public pages, not every generated table or interactive state. [Company’s EU-SILC account](https://cantabular.com/blog/protecting-magnitude-tables-with-cantabular) |

The customer evaluation and directly attributed case reports establish the use of Cantabular for census dissemination. The company’s magnitude article establishes the research direction and an initial implementation. Neither source reports a customer deployment or independent validation of the particular release policies evaluated in this repository.
